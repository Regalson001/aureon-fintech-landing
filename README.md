# AUREON — FinTech & Multi-Asset Trading Platform

AUREON is a premium, responsive fintech landing page concept designed to demonstrate modern front-end engineering for a multi-asset trading platform.

The project combines a sophisticated dark interface, illustrative market dashboard, responsive pricing comparison, security-focused design elements, and CSS-built desktop and mobile trading interfaces.

---

## Project Overview

AUREON explores how a modern financial technology platform can present complex market information through a clean, structured, and user-friendly interface.

The design focuses on:
- Financial data hierarchy and visual clarity
- Responsive layouts across desktop, tablet, and mobile
- Transparent account comparison interfaces
- Custom CSS and SVG visualizations
- Interactive front-end components
- Consistent visual design and accessibility

> **Important Notice:** AUREON is a fictional front-end portfolio project. It is not a broker, exchange, investment service, or financial product. All market prices, spreads, fees, execution descriptions, and interface data are illustrative placeholders. The project does not execute trades, connect to financial APIs, accept payments, or transmit form submissions.

## Responsive Design

AUREON is designed to adapt to different screen sizes.

- **Desktop:** Split hero, multi-column asset cards, full comparison table, and overlapping device mockups.
- **Tablet:** Adjusted grid layouts, flexible spacing, and resized interface components.
- **Mobile:** Collapsible navigation, stacked hero layout, two-column asset cards, horizontally scrollable comparison table, and compact device mockups.

## Accessibility Considerations

- Semantic HTML5 landmarks.
- Descriptive navigation labels.
- Accessible form labels.
- SVG chart alternative text.
- Native keyboard-accessible interactive elements.
- Reduced-motion preference support.
- Scrollable comparison table with an accessible description.

## Engineering Notes

### Illustrative Market Data
The market preview uses JavaScript-generated sample price movements. It is not connected to a live financial data provider.

### Front-End Form
The email form validates input locally and displays feedback. It does not submit information to a server or save user data.

### Trading Interface
The desktop and mobile trading interfaces are visual mockups. They do not execute orders or connect to brokerage services.
